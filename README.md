# SIGEL WMS

Sistema de Gerenciamento de Estoque e Logística desenvolvido para auxiliar os processos internos da **Luizinho Auto Peças**.

## 📌 Sobre o projeto

O SIGEL WMS é um sistema voltado ao gerenciamento de operações de estoque e logística, reunindo funcionalidades para apoiar as atividades internas da empresa.

## 🛠️ Tecnologias utilizadas

- **Frontend:** React e Vite
- **Interface:** Material UI (MUI)
- **Backend:** Python com Flask
- **Banco de dados:** MySQL
- **Controle de versão:** Git e GitHub

## 🔀 Organização e controle de alterações

O repositório utiliza o GitHub para controlar as versões do projeto e organizar as alterações no código.

- **Branch `main`:** destinada à versão principal do projeto e protegida contra alterações diretas.
- **Pull Requests:** utilizados para propor e revisar alterações antes de integrá-las à `main`.
- **Revisão por colega:** as alterações devem passar pela avaliação de outro colaborador antes da integração.
- **Proteção da branch:** as regras do GitHub ajudam a impedir alterações diretas e exigem revisão antes da integração.

## 🚀 Ambientes de implantação

O repositório possui ambientes configurados no GitHub para organizar as implantações:

- **Staging:** ambiente destinado à validação das alterações antes da produção.
- **Production:** ambiente de produção com aprovação obrigatória do responsável configurado no GitHub.
